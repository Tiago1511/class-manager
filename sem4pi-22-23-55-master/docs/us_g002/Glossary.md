Glossary
===========================================

## Business concepts ##

- **Teacher -** An individual responsible for teaching and administering a course to students.
- **Head Teacher -** An individual responsible for overseeing the educational program and faculty of a school or educational institution. The head teacher may also serve as the principal or director of the institution.
- **Student -** An individual who is enrolled in a course.
- **User -** Registered entity on the system
- **Manager -** An individual who is responsible for managing the system, including managing users, courses, and enrollment.
- **Course -** A study program consisting of several modules, typically, and designed to teach a specific subject.
- **Exam -** Exam that measures a student's understanding and proficiency in a given course subject.
- **Question -** An assignment presented to a student as part of an automaticExam, intended to assess the student's knowledge, understanding, and skills regarding a particular course subject.
- **Question Type -** Type of assignment presented to a student that can be multiple, 
- **Board -** A virtual space for sharing information, collaborating, or communicating.
- **Share Board -** This expression describes the act of allowing others to access and view a board to collaborate on teamwork. It's done virtually.
- **Post-it -** A note used for writing reminders or short messages.
- **Events -** Activities or occurrences that are scheduled to take place in a course or program, such as classes, meetings, or exams.
- **Class -** A single session of a course.
- **Meeting -** A scheduled event in which students and/or professors come together to discuss a particular topic or subject.
- **Enrollment -** The process of registering and signing up for a course or program.
- **Schedule -** A plan or timetable that outlines the various events and activities that are scheduled to take place in a course or program.


## Technical concepts ##

- **Linux -** Linux is a free and open source operating system.
- **Windows -** Windows is a very popular operating system developed by Microsoft.
- **Scripts -** A script is a program written in a scripting language that is interpreted rather than compiled. Scripts are often used in software development for automating tasks or performing repetitive actions.
- **Database -**  A database is a structured collection of data that is stored and accessed electronically.
- **Data Persistence -** Data Persistence refers to the ability of an application to store and retrieve data from a database or other storage system.
- **RDB -** Relational database (RDB) is a type of database management system (DBMS) that stores data in a structured format using rows and columns, and employs a set of rules called constraints to maintain the integrity of the data.
- **Programming language -** Programming language is a set of rules and instructions used to create software and applications.
- **HTML -** HyperText Markup Language (HTML) is the standard markup language used to create and structure content on the web, such as text, images, links, forms, and other elements.
- **AJAX -** AJAX is an abbreviation for Asynchronous JavaScript and XML, referring to a programming technique that allows content updates on a web page without the need to completely reload it.
- **Parser -** Parser is a software component that analyzes data or code to extract relevant information and perform specific actions based on the syntax and structure of the input.
- **ANTLR -** ANTLR is a parser generator tool used to build language and compiler tools.
- **Java -** Java is a high-level, object-oriented programming language used to develop applications for a variety of platforms, including desktop, web, and mobile devices.
- **Maven -** Maven is a dependency management and project build tool in Java that automates project construction and dependency resolution, making the software development and deployment process easier.
- **UML -** Unified Modeling Language (UML) is a standardized modeling language used to visualize, design, and document software systems using a set of graphical notations and diagrams.
- **Markdown -** Markdown is a lightweight markup language with plain-text formatting syntax used to create formatted content that can be easily converted to HTML or other formats.
- **Git -** Git is a distributed version control system used to manage source code and track changes made to it over time, allowing multiple developers to work on the same codebase simultaneously and merge their changes seamlessly.
- **GitHub -** GitHub is a web-based platform for version control and collaboration that allows developers to store and manage their code repositories, track changes, and work with others on shared projects.
- **Server -** A server is a computer program or device that provides services and resources to other programs or devices on a network, allowing them to access and share data, communicate with each other, and perform various tasks.
- **Threads -** Threads are lightweight, independent units of execution within a program that enable concurrent processing of multiple tasks and improve the performance and responsiveness of the system by utilizing the available processing resources more efficiently.
- **IP -** Internet Protocol (IP) is a set of rules that govern the format and transmission of data packets across networks, enabling devices to communicate with each other over the internet and other IP-based networks.
