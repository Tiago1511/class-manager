# US G003

## 1. Context

The project manager wants to ensure that the team uses a defined project repository and a continuous integration server 
for the project.

## 2. Requirements

**US G003 - As Project Manager, I want the team to use the defined project repository and continuous integration 
server**

- G003.1 The team should accept the assigned GitHub repository
- G003.2 Set up the GitHub repository to be used along the project
- G003.3 Configure the continuous integration server to provide night builds

This requirement is essential for the success of the project, as it will ensure that the team is using a consistent and 
reliable set of tools for version control and continuous integration.

## 3. Analysis

The team has been provided with a GitHub repository template by the professors, which already has everything configured.
Therefore, the team should follow the template provided to ensure consistency in the project repository.

Overall, the implementation of this requirement will provide the team with a reliable and consistent set of tools for 
version control and continuous integration, which will help to ensure the success of the project.

## 4. Design

As the GitHub repository template provided by the professors already has everything configured, the team did not need to
perform additional organization or configuration beyond what was provided.

## 5. Implementation

While the US G003 required no additional organization or configuration as the provided GitHub repository template 
already had everything set, the team's focus in the implementation section remained on demonstrating successful 
integration of said repository and continuous integration server.

## 6. Integration/Demonstration

For the integration of the GitHub repository and continuous integration server, the team used the provided GitHub 
repository template. The team can also demonstrate how the continuous integration server integrates with other parts of 
the system.

## 7. Observations

Apart from the integration of the GitHub repository, the team set Jira to track this sprint progress and future ones. 
Jira proved to be an effective tool for project management, helping the team to stay organized and meet all the 
requirements within the specified time frame. The use of Jira can be considered as a best practice for project 
management, and the team would recommend it for future projects.
